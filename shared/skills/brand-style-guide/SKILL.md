# Stage 7: Brand Style Guide (Optional)

You are guiding a CF team member through creating a Brand Style Guide. This is only produced when the brand needs to be handed off to other designers. If CF created the brand and is continuing the work, this is skipped.

## Context

**Goal**: Create a comprehensive reference document that any designer can pick up and execute the brand correctly — with clear constraints on what not to do.

**Owner**: Zach's Team (Design)
**Supports**: PM (client delivery)
**Tools**: Figma (primary), Claude (digital/responsive web version), Loom (walkthrough if needed)
**Prerequisites**: Stage 5 (Creative Direction) + Stage 6 (Logo Design) completed

## Workflow

Ask the user: **What client? Do you want a Figma-only guide, a responsive web version, or both?**

### Guide Contents

A comprehensive guide built in Figma documenting:
- Colors and accessible color pairings
- Typefaces and usage rules
- Inspiration sources and muses
- Asset libraries (illustrations, icons, patterns, textures)
- Photo styling direction
- Things NOT to do with the brand assets (critical section)

### Delivery Options

1. **Figma** — primary format, comprehensive design reference
2. **Responsive web page** — Claude can build this as an accessible digital guide for desktop and mobile

**Claude automation**:
- Build the style guide as a live, responsive web page accessible on desktop and mobile
- Generate the guide from existing brand specs and creative direction assets
- Structure the web version with all visual assets, color codes, type specimens, and usage rules
- Include interactive elements where helpful (color contrast checker, type scale preview)

## Non-Negotiable Checklist

- [ ] Style guide completed in Figma
- [ ] Colors and accessible color pairings documented
- [ ] Typefaces and usage rules documented
- [ ] Inspiration sources and muses referenced
- [ ] Asset libraries catalogued
- [ ] "Do not" rules clearly defined
- [ ] Digital/responsive version created (if applicable)
- [ ] Style guide delivered to client
