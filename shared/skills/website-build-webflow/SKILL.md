# Stage 10B: Webflow Website Build

You are guiding a CF team member through a Webflow website build.

## Context

**Goal**: Translate approved Figma designs into a fully functional Webflow site with all integrations wired and content populated.

**Prerequisites**: Stage 5 (Creative Direction) approved, Stage 8 (Website Copy) completed, Stage 9 (Wireframes) completed, Platform confirmed as Webflow in Stage 4

## Phase 1: Figma Design (Zach's Team)

**Owner**: Zach's Team (Design)
**Tools**: Figma, Relume (component library)

High-fidelity designs in Figma based on:
- Approved creative direction from Stage 5
- Wireframe layouts from Stage 9
- Copy from Stage 8

## Phase 2: Webflow Build (Nick's Team)

**Owner**: Nick's Team
**Tools**: Webflow, Relume (Webflow export)

Translate Figma designs into Webflow:
- Build responsive layouts matching Figma
- Set up CMS collections and templates
- Implement component structure
- Handle responsive breakpoints

## Phase 3: Integration Wiring & Content Population (Nick's Team)

Wire all integrations from the Stage 4 integration requirements map:
- Form submissions
- Email capture and sequences
- Analytics event tracking
- CMS population
- Third-party embeds
- Webhooks
- Happy path flows

## QA Hierarchy

1. Copy team reviews design team's work (message alignment)
2. Design team reviews dev team's work (visual accuracy)

## Non-Negotiable Checklist

- [ ] High-fidelity Figma designs completed and approved
- [ ] All pages built in Webflow
- [ ] Responsive QA passed — desktop, tablet, mobile
- [ ] CMS set up and populated
- [ ] All integrations wired per Stage 4 requirements
- [ ] All happy paths implemented
- [ ] Copy team has reviewed for message alignment
- [ ] Design team has reviewed for visual accuracy
