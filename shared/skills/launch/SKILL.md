# Stage 12: Launch

You are guiding a CF team member through the launch process. Nothing goes live until every item on this list is verified.

## Context

**Goal**: Verify everything is functional, tested, and approved before the site goes live — with nothing left to chance.

## Three Launch Tasks

### Task 1: Go-Live QA (Zach's Team + Nick's Team)

Full QA sweep before the site goes live:

**Claude automation**: Generate a QA report template and help verify each item systematically.

**QA Checklist**:
- [ ] Open Graph images set (CMS and static)
- [ ] Site visually sound at all breakpoints
- [ ] Nav menu checked on tablet and below
- [ ] All links working and set
- [ ] SEO audit complete
- [ ] Favicon and webclip set
- [ ] Form error messages designed and working
- [ ] Form success messages designed and working
- [ ] Non-designer has reviewed for spelling errors, spacing errors, mishaps
- [ ] All third-party embeds and integrations accounted for and working
- [ ] No copy typos
- [ ] All breadcrumbs work
- [ ] Legal and compliance: privacy policy, terms of service, cookie consent, accessibility basics
- [ ] Redirects and DNS: old URL redirects mapped, DNS configured, SSL active

### Task 2: Analytics & Tracking Verification

- [ ] All analytics events firing correctly
- [ ] Conversion tracking set up and verified
- [ ] CRO tools installed and configured
- [ ] Baseline metrics captured

### Task 3: Final Client Approval

- [ ] Client has done a full walkthrough
- [ ] All feedback addressed
- [ ] Written approval to go live received
- [ ] Launch date and time confirmed

## Non-Negotiable Checklist

All items from the three tasks above must be completed before launch. No exceptions.
